Воронка продаж — это основной элемент Kommo для организации процесса продаж. Каждая сделка движется по этапам воронки от потенциального клиента к закрытой сделке.

## Понятие воронки

Воронка состоит из **этапов** — статусов, через которые проходит сделка. Например:

- 📞 **Контакт** — новая сделка, только что получена информация о клиенте
- 🗣️ **Переговоры** — идет обсуждение условий
- 💼 **Предложение** — отправлено коммерческое предложение
- ✅ **Успешно** — сделка закрыта, клиент согласился
- ❌ **Отказ** — сделка отклонена клиентом

<Callout type="note">
Каждая воронка может иметь неограниченное количество этапов. Вы можете настроить структуру под свой бизнес-процесс.
</Callout>

## Создание воронки

<Step n="1">
**Перейдите в настройки воронок**

Откройте меню **Настройки** → **CRM** → **Воронки**
</Step>

<Step n="2">
**Нажмите кнопку «Создать воронку»**

На экране появится форма создания новой воронки.

<Screenshot src="/img/docs/funnel-work/step-1.png" alt="Создание воронки" caption="Форма для добавления новой воронки" />
</Step>

<Step n="3">
**Введите название и описание**

- **Название** — краткое и понятное имя (например, «Продажа услуг»)
- **Описание** — подробное описание назначения воронки
- **Цвет** — выберите цвет для визуального отличия от других воронок

<Video src="/img/docs/funnel-work/create-funnel.gif" caption="Анимация создания воронки с выбором цвета" />
</Step>

<Step n="4">
**Добавьте этапы**

Нажмите **+ Добавить этап** и вводите названия последовательно. Порядок важен — он определяет логику движения сделок.

<Callout type="tip">
Рекомендуем использовать единообразные названия этапов. Например: «Контакт», «Встреча», «Предложение», «Успешно» вместо разных вариантов написания.
</Callout>
</Step>

<Step n="5">
**Сохраните воронку**

Нажмите **Сохранить**. Воронка будет доступна при создании новых сделок.
</Step>

## Редактирование воронки

Отредактировать существующую воронку можно в любой момент:

1. Откройте **Настройки** → **CRM** → **Воронки**
2. Выберите воронку из списка
3. Нажмите на неё для редактирования
4. Вносите изменения:
   - Добавляйте новые этапы
   - Удаляйте ненужные этапы
   - Меняйте названия и порядок

<Callout type="warning">
Будьте осторожны при удалении этапов, если уже есть сделки на этих этапах. Их автоматически переместят на ближайший этап слева.
</Callout>

## Движение сделок по воронке

После создания сделки она автоматически появляется на первом этапе воронки. Для перемещения:

### На канбане

На странице **Сделки** используется канбан-доска:

<Screenshot src="/img/docs/funnel-work/kanban.png" alt="Канбан доска" caption="Перетягивайте карточки сделок между этапами" />

**Просто перетягивайте** сделку из одной колонки (этапа) в другую.

### Через редактор сделки

Откройте сделку и нажмите на текущий этап. Выберите нужный этап из меню.

<Video src="/img/docs/funnel-work/move-deal.gif" caption="Изменение этапа сделки в редакторе" />

## Аналитика воронки

Kommo автоматически собирает статистику по воронкам:

| Метрика | Описание |
|---------|---------|
| **Всего сделок** | Количество активных сделок в воронке |
| **Сумма сделок** | Общая стоимость всех активных сделок |
| **Успешно закрыто** | Количество и сумма закрытых сделок |
| **Коэффициент конверсии** | Процент сделок, перешедших на каждый этап |

Просмотреть аналитику можно:
- На рабочем столе в виджете воронки
- В разделе **Отчёты** → **CRM**
- На странице редактирования воронки

## Лучшие практики

<Callout type="tip">
**Совет**: Создавайте отдельную воронку для каждого типа продаж или бизнес-процесса. Например:
- Воронка для услуг
- Воронка для товаров
- Воронка для интеграций
</Callout>

<Callout type="tip">
**Совет**: Регулярно проверяйте и оптимизируйте структуру воронки. Если этап часто пропускается, возможно, его нужно удалить или переименовать.
</Callout>

## Частые вопросы

### Можно ли поменять порядок этапов?

Да, при редактировании воронки вы можете перетягивать этапы для изменения их порядка.

### Что произойдёт, если удалить этап с активными сделками?

Сделки будут автоматически переместены на ближайший этап слева от удаляемого этапа.

### Можно ли восстановить удалённую воронку?

К сожалению, нет. Удалённую воронку необходимо создать заново. Архивируйте неиспользуемые воронки вместо удаления.
