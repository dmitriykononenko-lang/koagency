Поля сделки — это параметры, которые хранят информацию о каждой сделке. Kommo позволяет создавать пользовательские поля под специфику вашего бизнеса.

## Встроенные поля

Каждая сделка уже имеет основные встроенные поля:

| Поле | Тип | Описание |
|------|-----|---------|
| Название | Текст | Название сделки (обязательное) |
| Ответственный | Контакт | Менеджер, отвечающий за сделку |
| Сумма | Число | Стоимость сделки в выбранной валюте |
| Дата закрытия | Дата | Планируемая дата закрытия сделки |
| Примечание | Текст | Описание или комментарии |
| Воронка | Выбор | Название воронки продаж |

<Callout type="note">
Встроенные поля не могут быть удалены, но они могут быть скрыты или переименованы в зависимости от роли пользователя.
</Callout>

## Создание пользовательского поля

### Где создавать поля

<Step n="1">
**Откройте настройки CRM**

В главном меню нажмите **Настройки** → **CRM** → **Поля сделок**
</Step>

<Step n="2">
**Нажмите кнопку «Добавить поле»**

На экране появится форма создания нового поля.

<Screenshot src="/img/docs/deal-fields-setup/step-1.png" alt="Добавление поля" caption="Интерфейс добавления нового пользовательского поля" />
</Step>

<Step n="3">
**Заполните основную информацию**

Введите:
- **Название поля** — как оно будет отображаться в системе (например, «Источник клиента»)
- **Тип поля** — выберите из доступных вариантов (см. ниже)
- **Обязательное поле** — отмечайте, если поле должно быть заполнено всегда

<Screenshot src="/img/docs/deal-fields-setup/step-2.png" alt="Параметры поля" caption="Форма с основными параметрами нового поля" />
</Step>

<Step n="4">
**Сохраните поле**

Нажмите **Сохранить**. Поле сразу появится в форме сделки.
</Step>

## Типы полей

Kommo поддерживает различные типы полей для разных данных:

### Текст
Простое текстовое поле для строк текста.
```
Пример: "Комментарий:", "Особые пожелания"
```

### Число
Поле для числовых значений с возможностью установки мин/макс значений.
```
Пример: "Количество", "Скидка (%)"
```

### Дата
Поле для выбора даты из календаря.
```
Пример: "Дата встречи", "День рождения"
```

### Время
Поле для выбора времени.
```
Пример: "Время встречи", "Время звонка"
```

### Выбор (Dropdown)
Поле с предопределённым списком вариантов. Пользователь выбирает один из них.

<Callout type="tip">
**Совет**: Используйте выбор для полей со строгими вариантами (источник, тип продукта, статус).
</Callout>

### Множественный выбор
Похож на выбор, но позволяет выбрать несколько вариантов одновременно.

### Связь
Поле для связи с контактом, компанией или другой сделкой.

### Файл
Поле для загрузки файлов, связанных со сделкой.

### URL
Специальное поле для веб-адресов с валидацией.

## Редактирование поля

Чтобы изменить пользовательское поле:

1. Откройте **Настройки** → **CRM** → **Поля сделок**
2. Найдите поле в списке и нажмите на значок редактирования
3. Измените нужные параметры
4. Сохраните изменения

<Callout type="warning">
**Осторожно**: Если изменить тип поля, существующие данные могут быть потеряны. Убедитесь, что нет важных данных в этом поле перед изменением типа.
</Callout>

## Удаление поля

Для удаления пользовательского поля:

1. Откройте **Настройки** → **CRM** → **Поля сделок**
2. Найдите поле и нажмите на значок удаления (🗑️)
3. Подтвердите удаление

<Callout type="warning">
**Важно**: После удаления поля все данные, хранящиеся в этом поле, будут удалены безвозвратно. Сделайте резервную копию перед удалением важного поля.
</Callout>

## Примеры полей для разных типов бизнеса

### Для сервиса разработки
- Тип проекта (выбор: Web, Mobile, Desktop)
- Бюджет (число)
- Технологический стек (текст)
- Дедлайн (дата)
- Статус дизайна (выбор: На утверждении, Утвержден, Отклонен)

### Для продажи товаров
- Тип товара (выбор: Электроника, Одежда, Книги)
- Количество единиц (число)
- Способ доставки (выбор: Самовывоз, Доставка)
- Дата доставки (дата)
- Трек-номер (текст)

### Для B2B сервисов
- Размер компании (выбор: Стартап, SMB, Enterprise)
- Количество лицензий (число)
- Тип контракта (выбор: Месячный, Годовой)
- Дата начала (дата)
- Условия оплаты (текст)

<Callout type="tip">
**Совет**: Не переусложняйте. Добавляйте только те поля, которые действительно нужны для работы. Слишком много полей замедляет работу команды.
</Callout>

## Доступность полей

После создания поля его видят все пользователи с правом на редактирование сделок. Для ограничения доступа:

1. Откройте **Настройки** → **Роли и разрешения**
2. Найдите нужную роль
3. В разделе **Доступ к полям сделки** выберите, какие поля видят пользователи этой роли

## Импорт существующих данных

Если у вас уже есть данные в другой системе, вы можете импортировать их в Kommo:

1. Подготовьте CSV файл с данными
2. Откройте **Настройки** → **Импорт**
3. Выберите тип данных (Сделки)
4. Загрузите файл и сопоставьте колонки с полями Kommo

<Callout type="note">
При импорте важно правильно сопоставить колонки источника с полями в Kommo. Используйте правильные форматы данных для каждого типа поля.
</Callout>
