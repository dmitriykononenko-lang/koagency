1. Summary

The widget runs in the user's browser inside the amoCRM account. Contact data is not sent to the operator's servers and is not stored by the operator.

2. Data the widget uses

  • Contact phone numbers: to determine the country, time zone, region, city and carrier.
  • Values of selected contact fields: so that fields already filled in are not overwritten.
  • The account's list of contact fields: to show them in the settings.
  • Widget settings: business hours and selected fields. They are stored in the amoCRM account.

3. How it works

The number is matched against tables included in the widget archive. Fields are written through the amoCRM API on behalf of the current user, and only the fields an administrator selected in the settings. No data is passed to third-party services.

4. Account access

On installation amoCRM sends a one-time code to the integration address. The operator does not exchange it for tokens and gains no account access through it. The widget's pages do not use cookies.

Page hosting

The privacy, support and connection pages are hosted by Vercel Inc. (USA). When they are opened, the provider technically processes the IP address and the request address, which carries the one-time code during installation. Contact data is not sent to these pages.

5. Support requests

If you contact support, the operator receives what you include in your message and uses it only to reply. To have your correspondence deleted, write to the address above.

6. Removal

Disable the widget in the amoCRM account and it stops working. Values it wrote to contact fields remain in your account and can be removed with amoCRM tools.

7. Accuracy

Country and region come from the numbering plan and show where the number was issued, not where the person is now.

8. Changes

New versions are published on this page. If the widget ever starts sending data to the operator's servers, this policy will be updated before that version is released.
