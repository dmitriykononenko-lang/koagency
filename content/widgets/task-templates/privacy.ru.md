# Политика конфиденциальности виджета «Шаблоны задач»

Редакция от 22.11.2026.

Эта политика описывает, как виджет «Шаблоны задач» для amoCRM (далее — виджет) работает с данными. Общая политика обработки персональных данных KO:AGENCY — на странице [koagency.me/legal/privacy](https://koagency.me/legal/privacy). Если они расходятся, для виджета действует этот документ.

## Коротко

- Виджет работает в браузере внутри вашего аккаунта amoCRM и для своей работы обращается к API того же аккаунта (`/api/v4`) с правами пользователя, который сейчас работает в amoCRM.
- Шаблоны хранятся в вашем аккаунте amoCRM. Разработчик к ним доступа не получает.
- Разработчику передаётся только контакт для связи: телефон, который вы указываете при установке, а также ID и поддомен аккаунта amoCRM. Подробнее — в разделе «Телефон для связи».
- Шаблоны, данные сделок, контактов, компаний и пользователей виджет никому не передаёт. Аналитику, cookie и счётчики не использует.

## Какие данные использует виджет

| Данные | Откуда | Зачем |
|---|---|---|
| Шаблоны: название, комментарий, тип задачи, срок, ответственный | вводят пользователи в редакторе шаблонов | чтобы ставить задачи по шаблону |
| Список пользователей аккаунта: ID и имя | API amoCRM, `/api/v4/users` | выбрать ответственного в шаблоне и показать его имя |
| ID и имя текущего пользователя | интерфейс amoCRM | назначить задачу на текущего пользователя |
| Типы задач аккаунта | API amoCRM, `/api/v4/account` | выбрать тип задачи в шаблоне |
| ID открытой сделки, контакта или компании и её ответственный | интерфейс и API amoCRM | привязать задачу к карточке и назначить ответственного за карточку |
| Создаваемая задача: текст, тип, срок, ответственный | шаблон | создать задачу через `/api/v4/tasks` |
| Телефон для связи | вводит администратор при установке (обязательное поле настроек) | связаться с вами по вопросам виджета, см. «Телефон для связи» |
| ID и поддомен аккаунта amoCRM | подпись запроса amoCRM (токен), виджет их не отправляет | понять, к какому аккаунту относится телефон |

Имена пользователей и данные карточек виджет держит только в памяти открытой вкладки браузера и никуда не сохраняет. В шаблоне сохраняется ID выбранного ответственного, а не его имя.

Комментарий шаблона — свободный текст. Не записывайте в него персональные данные клиентов: он виден всем, кто открывает редактор шаблонов или служебный список.

## Телефон для связи

При установке виджет просит указать телефон для связи — без него виджет не включается. Это нужно, чтобы поддержка KO могла связаться с вами по вопросам виджета и предупредить о важном: окончании пробного периода, оплате, обновлениях и сбоях.

- **Что передаётся:** телефон из настроек виджета, код и версия виджета; ID и поддомен аккаунта amoCRM сервер узнаёт из подписи запроса, которую выдаёт amoCRM. Email, имена пользователей, шаблоны и данные карточек не передаются.
- **Куда:** на сервер KO:AGENCY (dubli.koagency.ru, Россия) по защищённому соединению HTTPS. Оттуда контакт попадает в CRM KO:AGENCY (amoCRM), где мы ведём клиентов.
- **Когда:** после сохранения настроек виджета и при первом запуске, если отправить не удалось. Тот же номер повторно не отправляется. Если сервер недоступен, виджет продолжает работать и повторит отправку позже.
- **Технические журналы:** сервер записывает IP-адрес и время запроса для защиты от злоупотреблений; журналы хранятся не дольше 14 дней.
- **Кто видит:** сотрудники KO:AGENCY, которые занимаются поддержкой и продажами. Третьим лицам мы телефон не передаём и не используем его для рекламных рассылок сторонних компаний.
- **Сколько храним:** пока виджет установлен. Через 30 дней после отключения виджета запись об установке удаляется с сервера KO:AGENCY, а у контакта в CRM KO:AGENCY стирается телефон и добавляется примечание об этом. Сама карточка контакта в CRM остаётся: amoCRM не даёт удалить её через API. Из резервных копий данные пропадают в течение 14 дней.
- **Как удалить:** напишите на hello@koagency.me с адреса или из аккаунта, по которым мы можем вас узнать, и укажите поддомен аккаунта amoCRM. В течение 10 рабочих дней удалим запись с сервера и сотрём телефон у контакта в CRM KO:AGENCY. Сменить номер можно в настройках виджета — новый заменит прежний.

Указывая телефон и сохраняя настройки, вы соглашаетесь на его обработку для этих целей. Обработка идёт по общей политике [koagency.me/legal/privacy](https://koagency.me/legal/privacy).

## Где хранятся шаблоны

1. **Основное хранилище — служебный список вашего аккаунта** «Шаблоны задач (данные виджета)». Виджет создаёт его при первом сохранении шаблонов: один элемент `config` с полем «Данные», где шаблоны записаны в формате JSON. Список виден в разделе «Списки» amoCRM пользователям с правами на списки.
2. **Резервная копия — поле настроек виджета** в amoCRM. Его заполняет редактор в окне настроек виджета, когда администратор нажимает «Сохранить».

Оба места находятся внутри вашего аккаунта amoCRM. Данные хранит amoCRM по своей политике конфиденциальности.

## Кто видит данные

- Пользователи вашего аккаунта amoCRM — в пределах своих прав в amoCRM.
- Разработчик шаблоны и данные карточек не видит — только если вы сами пришлёте их в поддержку, например скриншот. Разработчик видит телефон для связи, ID и поддомен аккаунта (см. «Телефон для связи»).

## Сколько хранятся данные

Шаблоны — пока вы их не удалите. Виджет сам ничего не удаляет: ни при удалении шаблона из списка (меняется только содержимое служебного списка), ни при отключении или удалении виджета.

Чтобы удалить все данные виджета:
1. Удалите шаблоны в редакторе шаблонов или отключите виджет.
2. В разделе «Списки» amoCRM удалите список «Шаблоны задач (данные виджета)».
3. Если виджет ещё установлен, очистите поле шаблонов в настройках виджета и нажмите «Сохранить».
