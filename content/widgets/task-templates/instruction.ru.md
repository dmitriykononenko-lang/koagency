# Инструкция: «Шаблоны задач» для amoCRM

Виджет ставит задачу в один клик из карточки сделки, контакта или компании. Шаблон заранее задаёт комментарий, тип задачи, срок и ответственного.

## 1. Установка

1. В amoCRM откройте раздел **amoМаркет** и найдите «Шаблоны задач».
2. Нажмите **Установить**, примите условия и нажмите **Сохранить**.
3. Начнётся бесплатный пробный период. Оплата — в карточке виджета в amoМаркете.

Устанавливать виджет может только администратор аккаунта.

## 2. Создание шаблона

Создать шаблон можно в двух местах:
- в окне настроек виджета — amoМаркет → «Шаблоны задач»;
- в карточке сделки, контакта или компании — ссылка **Редактор шаблонов** в блоке виджета.

Порядок:
1. Нажмите **+ новый шаблон**.
2. Заполните поля:
   - **Название** — его видят сотрудники при выборе шаблона. Обязательное поле.
   - **Срок выполнения** — в момент создания, через 15 или 30 минут, через час, до конца дня, завтра, через 2 или 3 дня, через неделю.
   - **Выбор даты вручную** — включите, если дату и время нужно указывать при каждой постановке. Тогда срок из списка не используется.
   - **Ответственный** — текущий пользователь (кто ставит задачу), ответственный за карточку или конкретный сотрудник.
   - **Тип задачи** — любой тип из вашего аккаунта, включая собственные.
   - **Комментарий** — текст задачи. Если оставить пустым, текстом задачи станет название шаблона.
3. Нажмите **Сохранить**.

Шаблоны общие для всего аккаунта: шаблон, созданный одним сотрудником, видят все.

Чтобы изменить шаблон, нажмите на его название в списке. Чтобы удалить — на значок корзины справа. Удаление срабатывает сразу, без подтверждения.

### Как считается срок

Срок отсчитывается от момента постановки задачи по времени компьютера сотрудника:

| Вариант | Срок |
|---|---|
| в момент создания | сейчас |
| через 15 минут / 30 минут / час | сейчас + 15 мин / 30 мин / 1 ч |
| до конца дня | сегодня в 23:59 |
| завтра | ровно через 24 часа |
| через 2 дня / 3 дня / неделю | через 48 ч / 72 ч / 7 суток |

## 3. Постановка задачи

1. Откройте карточку сделки, контакта или компании.
2. В правой колонке найдите блок «Шаблоны задач» и нажмите **Поставить задачу по шаблону**.
3. Нажмите на нужный шаблон. В карточке шаблона видно, до какого времени будет срок, кому и какого типа будет задача.
4. Задача создаётся сразу и привязывается к открытой карточке. Внизу экрана появится «Задача создана».

Если в шаблоне включён выбор даты вручную, после нажатия на шаблон появится поле даты и времени. Укажите их и нажмите **Поставить задачу**.

## 4. Права пользователей

Виджет работает с правами того сотрудника, который сейчас в amoCRM. Отдельных ролей в виджете нет.

| Действие | Что нужно в amoCRM |
|---|---|
| Ставить задачи по шаблону | право создавать задачи; чтобы ставить задачи другим — право назначать их на других сотрудников |
| Создавать и менять шаблоны | право работать со списками (шаблоны лежат в служебном списке) |
| Первое сохранение шаблонов | право создавать списки — проще всего, чтобы первые шаблоны создал администратор |
| Открыть настройки виджета | права администратора |

Если прав не хватает, виджет покажет «Не удалось сохранить шаблоны» или «Не удалось создать задачу». Права настраиваются в разделе **Настройки → Пользователи**.

В выборе ответственного видны только активные сотрудники аккаунта.

## 5. Где хранятся шаблоны

В вашем аккаунте amoCRM:
- в служебном списке **«Шаблоны задач (данные виджета)»** — его виджет создаёт сам при первом сохранении, список виден в разделе «Списки»;
- резервно — в поле настроек виджета.

Не меняйте элемент `config` в служебном списке вручную: там шаблоны в формате JSON, ошибка в нём сбросит список шаблонов на резервную копию.

У виджета нет своего сервера, данные не уходят за пределы аккаунта. Подробнее — в [политике конфиденциальности](/widgets/task-templates/privacy).

## 6. Отключение и удаление

- **Отключить виджет** — amoМаркет → «Шаблоны задач» → **Отключить**. Шаблоны останутся в аккаунте и вернутся, если включить виджет снова.
- **Удалить шаблоны полностью** — после отключения откройте раздел «Списки» и удалите список «Шаблоны задач (данные виджета)». Виджет сам ничего не удаляет.
- Задачи, уже созданные по шаблонам, — обычные задачи amoCRM. Они остаются после отключения виджета.
